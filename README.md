# התאנה 3: מודל תלת־ממדי של פינוי בינוי מתחם האצ"ל, רחובות

מודל של המצב הקיים והמצב העתידי לפי תוכניות רח/2/5/46 ו־414-1113752, לבחינת צל, שמש ורוח, ולקריאת מיקומה של דירה אחת.

## מה יש כאן עכשיו

- `tasrit.html`: התסריט. שבע סצנות, תרשים מחושב של המתחם עם צל, ומה נדרש לשלב הבא.
- `data/site.json`: מקור הנתונים היחיד. תאי שטח, קווי בניין, מבנים להריסה, עצים, רחובות ו־983 מבני סביבה עם גובה.
- `source/`: מסמכי התוכנית המקוריים (הוראות, תשריטים, SHP, KML, DWG).
- `tools/build-data.py`: בונה את `data/site.json` מתוך `source/`.
- `tools/build-tasrit.py`: בונה את `tasrit.html` מתוך הנתונים ומתוך `tools/tasrit.template.html`.
- `tools/sun.py`: חישוב מיקום השמש ואורך הצל.

## בנייה מחדש

```bash
pip install pyshp pyproj
python3 tools/build-data.py
python3 tools/build-tasrit.py
```

## השלב הבא

בניית המודל עצמו (React, Three.js, suncalc, תצלום לוויין), אחרי קבלת תוכניות הבניינים ומיקום הדירה.
