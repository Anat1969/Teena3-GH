# התאנה 3: מודל תלת־ממדי של פינוי בינוי מתחם האצ"ל, רחובות

מודל של המצב הקיים והמצב העתידי לפי תוכניות רח/2/5/46 ו־414-1113752, לבחינת צל, שמש ורוח, ולקריאת מיקומה של דירה אחת.

## האפליקציה

ארבעה נושאים בסרגל העליון, מעל מודל אחד:

1. **המתחם:** מצב קיים מול מצב עתידי, על תצלום לוויין, עם נתוני כל בניין בלחיצה.
2. **שמש וצל:** מחוון שעה ותאריך, צל אמיתי, מפת שעות שמש על הקרקע, והשוואת השמש בגינה לפני ואחרי.
3. **רוח:** שלושה משטרי רוח וחשיפת כל חזית אליהם.
4. **הדירה שלי:** בניין, קומה וחזית. שעות שמש בכל עונה, מי מצל, רוח, מבט מהחלון, וניקוד הדירה הקיימת לפי מסמך העקרונות של השמאי.

## מבנה

- `src/lib/site.ts`: טעינת הנתונים, הבניינים והחזיתות.
- `src/lib/sun.ts`: מיקום השמש לפי שעון ישראל.
- `src/lib/shade.ts`: מפת גבהים ובדיקת צל. אותו חישוב משרת את הקרקע ואת הדירה.
- `src/lib/analysis.ts`: שמש בגינה, דוח דירה וחשיפה לרוח.
- `src/scene/Scene.tsx`: הסצנה התלת־ממדית.
- `src/ui/Panel.tsx`, `src/App.tsx`: הממשק.
- `tests/sun.test.ts`: בדיקות לחישוב השמש והצל. `npm test`.
- `data/site.json`: מקור הנתונים היחיד, נבנה מ־`source/` בכלי `tools/build-data.py`.
- `tasrit.html`, `public/tasrit.html`: התסריט.

## הרצה

```bash
npm install
npm run dev
```

## בנייה מחדש של הנתונים

```bash
pip install pyshp pyproj
python3 tools/build-data.py
python3 tools/build-tasrit.py
```

## מה חסר

- תוכניות הבניינים: יחליפו את מעטפת קו הבניין בנפח האמיתי ובמיקום הדירות.
- כתובות הבניינים הקיימים, כדי לזהות את הדירה של היום.
- שושנת רוחות מדודה של השירות המטאורולוגי.
