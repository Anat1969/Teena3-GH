# התאנה 3: מודל תלת־ממדי של פינוי בינוי מתחם האצ"ל, רחובות

מודל של המצב הקיים והמצב העתידי לפי תוכניות רח/2/5/46 ו־414-1113752, לבחינת צל, שמש ורוח, ולקריאת מיקומה של דירה אחת.

## האפליקציה

ארבעה נושאים בסרגל העליון, מעל מודל אחד:

1. **המתחם:** מצב קיים מול מצב עתידי, על תצלום לוויין, עם נתוני כל בניין בלחיצה.
2. **שמש וצל:** מחוון שעה ותאריך, צל אמיתי, מפת שעות שמש על הקרקע, והשוואת השמש בגינה לפני ואחרי.
3. **רוח:** שלושה משטרי רוח וחשיפת כל חזית אליהם.
4. **הדירה שלי:** בניין, קומה וחזית. שעות שמש בכל עונה, מי מצל, רוח, מבט מהחלון, וניקוד הדירה הקיימת לפי מסמך העקרונות של השמאי.

## מבנה

- `src/lib/site.ts`: טעינת הנתונים, הבניינים והחזיתות.
- `src/lib/sun.ts`: מיקום השמש לפי שעון ישראל.
- `src/lib/shade.ts`: מפת גבהים ובדיקת צל. אותו חישוב משרת את הקרקע ואת הדירה.
- `src/lib/analysis.ts`: שמש בגינה, דוח דירה וחשיפה לרוח.
- `src/scene/Scene.tsx`: הסצנה התלת־ממדית.
- `src/ui/Panel.tsx`, `src/App.tsx`: הממשק.
- `tests/sun.test.ts`: בדיקות לחישוב השמש והצל. `npm test`.
- `data/site.json`: מקור הנתונים היחיד, נבנה מ־`source/` בכלי `tools/build-data.py`.
- `tasrit.html`, `public/tasrit.html`: התסריט.

## תוכניות הבניינים

- `source/plans/`: תוכניות בניין A (תאים 102 ו־103), בניין B (תא 101) ובניין C (תא 104).
- `tools/build-buildings.py`: מחלץ את קו המתאר של הקומה הטיפוסית ואת הדירות בכל קומה, וממקם אותם במתחם לפי קו המגרש וקו הבניין שבגיליון. הפלט: `data/buildings.json`. ההרצה אורכת כמה דקות.
- טבלת הדירות המוצעות אינה נשמרת בריפו, כי יש בה שמות דיירים. ממנה נלקחו רק שטחי המכר לפי טיפוס וסימון דירות התמורה.

```bash
pip install pymupdf opencv-python-headless scipy
python3 tools/build-buildings.py
```

## חתך בקומה

כשבוחרים דירה ולוחצים "חתך בקומה", הבניין נחתך בקומה שלה, והקומה כולה מוצגת: קירות חתוכים, שרטוט התוכנית על הרצפה, גרעין המדרגות והמעליות, והדירות השכנות. הדירה של ענת מודגשת עם שמות החדרים.

- `tools/build-floors.py`: בונה את `public/floors/` לכל הקומות בכל הבניינים.
- `tools/build-apartment.py`: בונה את `data/apartment.json`, קו המתאר והחדרים של הדירה של ענת.

## גיליונות ההיתר

גיליונות ההיתר של 101, 102, 103 ו־104 (חתכים, חזיתות, קומת פיתוח ותוכנית העמדה) נמצאים בדרייב של ענת ולא בריפו, כי כל אחד מהם כ־40 מ"ב.
מהם נלקחו, ונרשמו ב־`tools/build-buildings.py`:

- מפלסי הקומות וגובה ראש המעקה, מחתך 2-2 של כל בניין (`SECTIONS`).
- מיקום בניין 103 והיותו תמונת ראי של 102, מתוכנית ההעמדה 1:500 (`SITE_103`).

## מה חסר

- חדרי המדרגות והמתקנים שמעל הגג אינם מוצגים. הצל מחושב עד ראש המעקה.
- כתובות הבניינים הקיימים, כדי לזהות את הדירה של היום.
- שושנת רוחות מדודה של השירות המטאורולוגי.
